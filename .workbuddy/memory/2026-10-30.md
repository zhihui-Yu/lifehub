### 架构决策（已落地，后续勿推翻）

- **技术栈**：TypeScript 核心层 + Vite/React/MUI/Tailwind Web 端 + Node 同步服务骨架。
  **不用 Flutter** —— 本机未安装 Flutter SDK，且需求文档 3.4 节本身要求「Web 优先、禁止一上来全端一起生成」。
  核心层 `packages/core` 保持**零 DOM、零 React 依赖**，未来 Flutter 侧可通过移植 Dart / dart:ffi / JS 互操作复用。
- **架构模式**：Ports & Adapters（六边形）。核心层只依赖 4 个注入端口：
  `CryptoProvider`（WebCrypto+noble scrypt / node:crypto / noble-ciphers 兜底）、`StorageAdapter`（Dexie / 内存替身）、`Clock`、`DekProvider`。
- **金额**：一律「分」单位整数 `amountMinor` + 独立 `currency`；解析**全程不经过 parseFloat**（字符串切分）。
- **时间**：`occurredAt` ISO 8601 UTC + 独立 `localDate`(YYYY-MM-DD) + `sourceTimeZone`(IANA)；跨天判定只比 `localDate` 字符串。
- **加密**：口令 → scrypt → 主密钥 → 包裹 DEK → AES-256-GCM 加密业务数据；AAD 绑定 `entityType+entityId+keyVersion`；**不存口令哈希**，用哨兵密文 `lifehub:verify:v1` 校验。
- **索引明文列**（本地库唯一明文，7 个）：`entityType / localDate / occurredAt / createdAt / updatedAt / version / deviceId`。金额、方向、对方、备注、分类**全在密文内**。索引列不进同步载荷与备份。

### 主理人裁定的两处设计分歧

- **A-1 退款表达**：`direction` 取值 `income | expense | refund`，refund 金额恒为正。理由：用「支出 + 负向标记」表达退款会让统计把退款算成负支出。已同步修订 PRD A-02 验收标准。
- **A-2 索引明文列**：接受最小集方案。须在 ADR-006 与 README 隐私章节**明示这 7 个列名**，让用户知情。

### 恢复码设计增量（主理人批准）

原设计存在致命缺陷：`buildRecoveryBundle` 用独立随机 recoverySalt，但 `unlockWithRecoveryCode` 用 vault 的 salt —— 两侧对不上，恢复码永远解不开。改为：
`RecoveryMeta` 扩为 `{id, checksum, exported, createdAt, salt, kdfParams, wrappedDek}`，
恢复码派生密钥**包裹 DEK**；重新生成恢复码 = 新盐值 + 新包裹同一 DEK（DEK 本身不变）→ 旧码立即失效。
**恢复码明文绝不落库**（X-03 ⑤ 红线）。
